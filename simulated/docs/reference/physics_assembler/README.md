# Physics Assembler Reference Archive

此目录是原航空学物理装配器的不可直接编译参考归档，不是 Bedrock 插件模块。

- `legacy-mixins/`：Mixin 和 Mixin 接口原始空壳；不在脚本运行时加载。
- `legacy-metadata/`：NeoForge 元数据、服务发现和 Mixin 配置；Bedrock 侧由 pack manifest 承担容器声明。
- `legacy-blockstates/`、`legacy-ponder/`、`legacy-advancements/`：没有直接 Bedrock 目录对应的 Java 资产。
- `generated/`：common/NeoForge 构建生成物，保留来源，不作为手写 Bedrock 数据源。
- `legacy-assets/`：原始完整语言和声音注册表，便于追溯；RP 中只保留装配器条目。
